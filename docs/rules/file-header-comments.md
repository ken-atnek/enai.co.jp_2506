# ファイルヘッダーコメント

## 方針

既存のTSXとSCSSには、用途・パス・更新日を示すヘッダーがあります。新規ファイルでは既存形式に合わせますが、既存ファイルへ一括追加・一括更新はしません。

## TSXテンプレート

```tsx
/* =======================================
 * 梨園 ページまたはコンポーネント名
 * URL: src/app/example/page.tsx
 * Created: YYYY-MM-DD
 * Last updated: YYYY-MM-DD
 * ======================================= */
```

## SCSSテンプレート

`@use` が必要な場合はSassの仕様に従ってファイル先頭に置き、その後へヘッダーを記載します。

```scss
@use "variable" as *;
/* =================================
 * ページまたはコンポーネント名
 * ------------------------------ */
```

## 運用ルール

- パスはプロジェクトルート基準で記載する
- 日付は `YYYY-MM-DD` 形式を使う
- 既存ヘッダーがあるファイルを修正した場合だけ、必要に応じて `Last updated` を更新する
- コピー元のページ名や誤ったパスを残さない
- コードから明らかな説明コメントを増やさない
- 制約、例外、外部仕様など、コードだけでは分からない意図を優先して残す
