# CSSのlinear()でUIが軽快になる! スプリングアニメーション活用術13選

## URL

https://ics.media/entry/260402/

## この記事の要点

- CSSの `linear()` は、複数の進行点を指定して複雑なイージングを近似できる
- `linear()` でスプリング風のイージングを作ると、CSS Transition / Animationだけで軽快なUIフィードバックを作れる
- 向いているUIは、セグメントボタン、トグル、トースト、モーダル、ポップオーバー、フローティングボタン、アコーディオン、サイドメニュー、アクションシート、削除時の退場モーション、フォームやボタンのモーフィングなど
- スプリングは「少し行き過ぎて収束する」動きにより、操作した感や状態変化を伝えやすい
- `linear()` の値は手書きで作り込むより、Anime.js の Easing Functions Editor などで調整してCSSへ書き出す方が現実的
- スプリング系の主な調整軸は `mass`、`stiffness`、`damping`、`velocity`
- Elasticは派手に揺れやすく、スプリングは軽い・重い・硬い・柔らかい・減衰の強弱を調整しやすい

## 実案件で使うなら

小さなUIの押下、選択状態の移動、メニューや通知の出現など、ユーザーの操作結果を自然に伝えたい場面で使う。

特に相性がいいのは次のような場面。

- タブやセグメントボタンの選択背景が移動する
- トグルのノブが端まで移動する
- トーストやポップオーバーが発火元の近くから出る
- モーダルやアクションシートが唐突に出ないようにする
- アコーディオンやサイドメニューの開閉を柔らかく見せる
- 送信ボタンや検索フォームの形状変化を連続した動きにする

## 判断基準

- 「動きが気持ちいい」だけでなく、操作結果や関係性が分かりやすくなるかを見る
- コーポレート、医療、士業、不動産、高額商材など落ち着きが必要なサイトでは弱めに使う
- キャンペーン、採用、プロダクト紹介、アプリUIなど軽快さが価値になる画面では採用しやすい
- `linear()` は広く使えるが、古いブラウザ対応が必要な案件では通常イージングへのフォールバックを確認する
- JSの物理演算スプリングが必要なのは、ドラッグやジェスチャーなど速度の連続性が重要な場合

## 避けること

- 全要素に同じスプリングを当てる
- 大きなレイアウト移動や本文テキストに強い跳ねを入れる
- フォーム送信、決済、予約など慎重な操作で派手に揺らす
- `transition: all` に頼り、意図しないプロパティまで動かす
- Elasticとスプリングを同じ「跳ねる動き」として扱う

## 実装メモ

```scss
:root {
  --ease-spring-soft: linear(0, 0.18, 0.42, 0.72, 0.95, 1.06, 1.04, 1.01, 0.99, 1);
}

.menu {
  opacity: 0;
  transform: translateY(-8px) scale(0.98);
  transition:
    opacity 0.2s ease-out,
    transform 0.45s var(--ease-spring-soft);
}

.menu.is-open {
  opacity: 1;
  transform: translateY(0) scale(1);
}
```
